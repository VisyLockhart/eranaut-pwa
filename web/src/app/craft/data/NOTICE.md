# 配件製作資料集 — 來源說明

本資料夾(`web/src/app/craft/data/`)中的 `base.json`、`crafts.json`、`recipes.json` 是**第三方遊戲資料的整理結果**,**不適用本專案的 MIT 授權**。

## 來源

GitHub `cxzzsf0896753245657-hue/Final-Fantasy-XIV-watre`(**該 repo 未附授權條款**)中的潛水艇配件製作資料。
僅取用事實:繁體中文名稱、配方成分與數量、製作產量、素材分類。**不複製其檔案或資料結構**,欄位與結構是本專案重新設計的。

交叉驗證(不取用資料):5p 工坊(https://5p.nbbjack.com/#/workshop)的顯示結果。

## 改動說明

- 少數配方與遊戲不符處,依遊戲內截圖校正(翼膠、星極油),記錄於 build.mjs 與 TODO.md。
- 欄位名稱與結構重新命名與整理;配件名稱、等級以航線資料集(`route/data/parts.json`)為準(例如「甲鱟級」)。
- 素材分組由本專案自訂(碎晶 / 水晶 / 晶簇 / 礦石 / 金屬 / 木材 / 布料與皮革 / 鍊金原料 / 其他)。
- 不收職業、製作等級、物品等級等本功能用不到的欄位。
- 骨架不列為獨立品項,改以「同級原版配件 ×1」表示。

## sources.json(素材的其他取得管道)

`sources.json` 是**第二份第三方資料的整理**,**不適用 MIT 授權**,以 **CC BY-NC-SA 3.0** 釋出(轉載或改作請保留來源說明、以相同授權分享,且不得商業使用)。

- 來源:灰機 wiki(https://ff14.huijiwiki.com/ )各物品頁面的「通過商店購買」「通過兌換獲得」兩節,授權標示為 CC BY-NC-SA 3.0。
- 取用方式:只取事實欄位(價格、商人、座標、兌換物與數量、前置任務名稱),不複製頁面文字。網站有機器人驗證,由人工通過驗證後在同一個分頁以同源請求逐頁讀取(間隔 1 秒),不繞過任何防護。
- 空賊黃銅、空賊白鋼、薰衣草、風茄的兌換品項,另以遊戲內「以物易物」畫面截圖交叉核對(只用來核對,不取用資料)。
- 名稱由簡體轉繁體(opencc `cn→twp`);少數物品名稱灰機與繁中服不同,以別名對照(矽岩 / 硅岩、堅鋼 / 精金等)。NPC、地名、任務名可能與繁中服的用字不同。
- 其他貨幣(例如栎木幣)的兌換已整理在 `hidden`,畫面不顯示。
- 產生方式:`tools/craft-data/sources.mjs`(輸入 `tools/craft-data/wiki-raw.json`)。
- 畫面上不標示來源,來源說明只放在「資料授權」頁面。
